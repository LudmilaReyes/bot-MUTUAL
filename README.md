# Portafolio de Ludmila Reyes
Selección de proyectos desarrollados a medida para clientes. Los datos sensibles y la identidad visual han sido anonimizados para resguardar la privacidad de cada negocio.

Landing Pages Inmobiliarias: Páginas orientadas a la venta de desarrollos y barrios privados. Diseño moderno enfocado en la conversión y filtrado de leads. Cuenta con integración directa a Google Sheets, permitiendo al cliente acceder a su base de registros en tiempo real y de forma centralizada.

ChatBot Institucional con Handoff: Asistente conversacional estructurado en 5 flujos temáticos independientes. Incluye un sistema de transferencia a operador humano integrado con Telegram. Cada consulta crea un "Tema" en un grupo administrativo privado, permitiendo al equipo coordinar derivaciones y tareas internamente sin exponer esa logística al cliente final.

Página Web Institucional (Estática): Maquetación y estructura semántica desarrollada netamente en HTML. Optimizada para garantizar tiempos de carga mínimos, alto rendimiento y una excelente indexación en motores de búsqueda (SEO). Diseño responsive enfocado en la presentación clara de la identidad y servicios de la empresa.

Página Web Institucional (Dinámica): Desarrollo con lógica del lado del servidor utilizando PHP. Implementación de ruteo dinámico, procesamiento seguro de formularios de contacto y panel de administración básico para la autogestión de contenido. Los datos se gestionan mediante bases de datos relacionales robustas (como PostgreSQL), asegurando escalabilidad y un manejo eficiente de la información corporativa.
